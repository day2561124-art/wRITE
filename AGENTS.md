# Engineering agent instructions

For software engineering work, read [docs/ENGINEERING-QUALITY-METHODS.md](docs/ENGINEERING-QUALITY-METHODS.md) and apply its three methods proportionately to the task. These are guidance for the GPT-led engineering process, not authorization to bypass existing project-specific constraints, Nexa/Pi contracts, Workspace/Journal/Checkpoint, verification, integration or deployment gates.

Keep ordinary implementation decisions autonomous within authorized scope. Preserve exact test and review evidence; distinguish unavailable independent review from self-review. Do not install Superpowers or add a second engineering runtime solely to follow this guidance.

For Nexa/Pi execution, retain [the existing autonomous engineering entrypoint](docs/PI-AUTONOMOUS-ENGINEERING.md) and applicable formal authorization rules.
