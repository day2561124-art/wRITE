# Observer-grounded dialogue

原生對話需由呼叫端明確開啟。在準備與提交 World turn 時，對同一個 session 傳入 `groundDialogueReferents: true` 與 `learnDialogueReferents: true`。既有預設模式不變。

- 角色從自身感知與已發生的對話建立指涉。僅有主題、指涉不明或話題轉換時，不用上一輪的物件記憶補空白。
- 角色能針對不清楚的描述追問。後續的簡短回覆須來自原對話對象，且上一輪的追問須實際發出，才會延續該指涉。
- 回答區分當下看見、曾親眼看見與聽誰說過。過去讀到的面板數值不是即時狀態。複查需要實際選擇移動，由 World 判定是否成功，再由角色重新觀察。讀不到時會說無法確認。
- 回答與移動以候選動作呈現，仍由既有選擇、因果與提交流程處理。沒有新增客戶端預設值，也沒有更動站點部署。

執行 `node tests/run-communication.mjs` 可驗證對話邊界與原生 World 整合。新增回歸覆蓋指涉、澄清、來源驗證、回憶舊面板，以及走近後讀取、路徑阻擋、指涉變更和拒絕移動。
