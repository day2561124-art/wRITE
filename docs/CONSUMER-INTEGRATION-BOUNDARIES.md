# 通用角色腦與下游遊戲的權責邊界

此專案只提供作品無關的認知與 World 驗證機制；不擔任任何特定遊戲的劇情資料庫或 NPC 存檔。

## 通用核心持有的資料

- 感知、注意、主觀記憶、信念、推理、目標、行動、學習與通訊的通用**結構、演算法、介面及驗證規則**。
- 不依賴特定作品的測試人物、合成世界與測試用收據。測試資料不得被誤認成任何使用者的正式角色記憶。
- 機制缺陷的最小重現、抽象效能剖析與正式回歸驗收。

## 下游應保留的資料

- 特定作品／世界的角色卡、角色實際記憶、關係、劇情進度、存檔、世界事件與結算紀錄。
- 具名角色的整合／長跑測試、場景特有的效能結果、專案工程流水帳與部署紀錄。
- 原始作品的正確性與角色行為驗收，不可用通用核心的合成測試代替。

## 跨專案缺陷與更新流程

1. 下游先保留具名測試、重現環境、敏感內容及完整日誌，對外只提交去脈絡化、必要的最小重現。
2. 本專案收到一般化缺陷後，只修改通用機制，使用與下游作品無關的回歸測試驗收。
3. 如需追溯，可使用外部 Issue／PR 連結，但不複製下游的角色記憶、劇情或整份工程日誌。連結是外部證據，不代表資料歸屬。
4. 修補進入本專案的 `main` 後，下游必須自行固定版本，重跑世界驗證、角色記憶隔離及長跑測試，並決定是否採用。
5. 效能改善不能靠省略正式因果驗證、跳過主觀記憶隔離或偽造已完成的自主決策。

歷史 PR 中可能存在指向特定下游驗收的引用，應保留可追溯的技術證據；本規範對新工作的紀錄歸屬生效，不應事後改寫已合併的測試結果。
